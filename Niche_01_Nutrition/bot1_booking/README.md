# 🌿 NutriBooking Bot (Лид-магнит: Онлайн-запись на консультации)

## Назначение
Автоматическая квалификация пациентов, выбор услуги превентивного врача/нутрициолога и бронирование слота 24/7 без участия администратора.

## Промпт для аватарки Midjourney / Google Flow
`Modern minimalist medical logo, emerald green and soft cream palette, stylized leaf merging with stethoscope, vector illustration, clean lines, luxury clinic aesthetic --ar 1:1`

## Команды бота
- `/start` - Запустить воронку записи и выбор услуги

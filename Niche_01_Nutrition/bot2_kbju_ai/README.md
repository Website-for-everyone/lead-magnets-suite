# 🔬 NutriScan AI Bot (Лид-магнит: Калькулятор метаболизма & Чек-ап дефицитов)

## Назначение
Вовлекающий лид-магнит с вирусным расчетом КБЖУ по формуле Миффлина-Сан Жеора, выявлением дефицитов и выдачей PDF-руководства за подписку на Telegram-канал.

## Промпт для генерации аватара в Google Flow / Midjourney
`Futuristic nutrition laboratory, holographic DNA and avocado icon, glowing green neon accents, clean dark UI backdrop, 3D icon render --ar 1:1`

## Команды
- `/start` - Расчет метаболизма и выявление симптомов
